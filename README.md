# Mural Interativo · Discovery de Produto IA

Este repositório contém o **Mural Interativo V1**, uma ferramenta visual e leve projetada para apoiar o processo de Discovery de Produtos e iniciativas de Inteligência Artificial. 

Ele centraliza o mapeamento do cenário atual (AS-IS), o desenho da solução futura (TO-BE) e o planejamento de experimentos, substituindo a fragmentação de documentos por uma visão única e acionável.

## 🎯 Principais Funcionalidades
A ferramenta é dividida em etapas lógicas do Discovery:
* **Entender:** Central de controle, contexto do projeto, mapeamento de stakeholders, dores e ferramentas atuais.
* **Mapear:** Cadeia de valor e matriz de carga cognitiva para identificar gargalos reais.
* **Escolher:** Levantamento de oportunidades de IA e matriz de priorização (Impacto × Complexidade).
* **Desenhar:** Casos de uso detalhados (interação Humano × IA), arquitetura e visão TO-BE completa.
* **Executar & Validar:** Planejamento ágil (método 3-3-3), roadmap visual, controle de certezas, suposições e dúvidas (CSD).

## 🚀 Como acessar
O mural foi construído como um **arquivo HTML único** (Single File Application). Ele não requer instalação, banco de dados ou backend complexo; tudo roda perfeitamente direto no navegador.

Para visualizar:
1. Acesse o link do [GitHub Pages] *(Insira aqui o link do seu site gerado pelo GitHub Pages, ex: https://seu-usuario.github.io/nome-do-repositorio)*
2. Ou faça o download do arquivo `index.html` e abra-o com duplo clique em qualquer navegador moderno.

## 🛠 Como usar e salvar seus dados
A arquitetura deste mural salva o estado atual do projeto **localmente no seu navegador**.

* **Editando:** Use os botões "Editar", "Adicionar" e a interface de arrastar e soltar (drag and drop) diretamente na tela para preencher as informações do seu projeto.
* **Salvando e Compartilhando:** Para não perder seus dados ou para enviá-los a um colega, vá até a **Central de Controle** e clique em **Exportar JSON**. Um arquivo de backup será baixado.
* **Restaurando:** Para carregar dados previamente salvos, clique em **Importar JSON** e selecione o arquivo baixado. Você pode optar por substituir o projeto inteiro ou apenas mesclar informações novas.
